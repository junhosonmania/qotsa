QOTSA — PERFECTH | SEOUL LISTENING PARTY

사용 방법
1. index.html과 vercel.json을 새 GitHub 저장소의 최상위에 업로드합니다.
2. Vercel에서 저장소를 Import합니다. Framework: Other / Build Command: 빈칸 / Output Directory: .
3. Vercel Settings > Domains에 qotsa.beggarskorea.com을 추가합니다.
4. 아임웹 DNS에서 CNAME을 추가합니다. 이름은 qotsa.beggarskorea.com 전체 주소로 넣고, 대상 값은 이번 Vercel 프로젝트에 표시되는 값을 복사합니다.

이미 배포한 뒤 수정할 때는 index.html 하나만 교체하면 됩니다.
폰트, 로고, 사진과 손글씨 페이지 이미지는 모두 index.html에 포함되어 있습니다.

최종 수정
- 1번 흑백 정원 단체사진을 헤더 최상단으로 이동.
- 상단 SEOUL LISTENING PARTY / GIMBAB RECORDS.
- 커버 아래 Perfecth 원본 로고 사용, 일시 표기는 작게 유지.
- 바이오 4문단 전문 표시.
- 멤버 캡션은 지정한 Jon / Troy / Josh / Michael / Dean 순서, 단체사진 캡션 없음.
- Word Final 파일 9곡의 225행을 모두 한국어로 번역.
- 언어 전환 버튼 없이 한국어 텍스트와 손글씨 원본 이미지를 함께 표시.
- 카운터 판매 문구는 하단의 작은 안내로 표시.

손글씨 PDF는 최종 Word와 다른 초안 표현을 포함합니다. 번역은 Word Final을 기준으로 했습니다.
